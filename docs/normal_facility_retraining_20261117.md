# 정상 사례 보강 후 시설물 재학습 비교

## 방법

기존 주간 가드레일·맨홀 자료에 새 정상 장면의 **train과 val만** 각 분할에 합쳐 같은 ROI HOG·색상 특징 및 OpenCV RTrees 설정으로 두 모델을 처음부터 각각 재학습했다. 기존 시선유도봉, 가드레일, 맨홀 모델 및 데이터는 덮어쓰지 않았다. 차량 충돌과 신호등은 학습에 넣지 않았다.

세션당 2·6·12·18·22번 프레임을 사용하되 기존 실험과 같이 차량 정답 박스가 기준 ROI의 3% 초과 겹치는 프레임을 제외하고, 남은 점수의 평균을 세션 점수로 사용했다. 5장 모두 제외된 세션은 평가하지 않았다. 신규 모델의 임계값은 기존 자료와 추가 자료를 합친 validation에서 F1을 최대화하도록 고르고(동률이면 높은 값), 기존 모델은 이전 validation에서 정한 값을 유지했다. 가드레일 임계값은 기존 0.45 → 신규 0.50, 맨홀은 기존 0.45 → 신규 0.40이다. 따라서 아래 수치는 모델과 각각의 검증 임계값을 결합한 결과이며 모델 가중치만의 효과는 아니다.

기존 test의 세션과 이전 모델 점수를 이전 결과 파일과 비교해 동일함을 확인했다. 두 모델 모두 정확히 같은 시험 세션을 평가했다. 새 train은 가드레일 정상 33·이상 15세션(229프레임), 맨홀 정상 25·이상 10세션(175프레임)이다. train/val/test는 이전에 전체 세션·시드·정확한 이미지 중복 검사를 통과했다.

## 시험 결과

| 대상과 시험 자료 | 정상 오경고 기존 → 재학습 | 이상 탐지 기존 → 재학습 | 이상 누락 기존 → 재학습 |
|---|---:|---:|---:|
| 가드레일 기존 시험 | 5/5 → 3/5 | 15/15 → 11/15 | 0/15 → 4/15 |
| 맨홀 기존 시험 | 3/5 → 0/5 | 10/10 → 7/10 | 0/10 → 3/10 |
| 가드레일 추가 정상 시험 | 25/25 → 8/25 | 이상 사례 없음 | 이상 사례 없음 |
| 맨홀 추가 정상 시험 | 17/20 → 3/20 | 이상 사례 없음 | 이상 사례 없음 |

기존 시험에서 신규 가드레일 모델은 휨 1개와 파손 3개를 놓쳤고, 맨홀 모델은 열린 맨홀 3개를 놓쳤다. 추가 정상 시험에서의 잔여 오경고는 가드레일 8개, 맨홀 3개였다. 정상과 이상의 비용을 함께 고려하면 현재 재학습 결과를 실도로 사용 가능한 개선으로 판정할 수 없다. 기존 시험의 상태 분류 AP는 가드레일 0.895→0.872, 맨홀 0.954→0.954(반올림)이며 객체 검출 AP가 아니다. 추가 시험은 정상만 있어 그 부분의 AP를 계산하지 않았다.

## 한계와 산출물

test의 차량 통과 가드레일 세션은 기존 5개와 추가 5개가 모두 제외됐고, 추가 맨홀 차량 통과 5개도 모두 제외됐다. 따라서 가림 중 오경고나 이상 탐지 성능은 평가되지 않았다. 2차원 박스 겹침은 정확한 가시성 판단이 아니다. 정상·이상 합성 정답은 사람의 검수 전이며 같은 Unity 도시·에셋과 유사한 시야를 공유한다. 기존 test와 새 train 사이에도 비슷한 ROI가 관찰돼 독립 현장이나 새로운 CCTV에서의 성능이라고 주장할 수 없다. 이미 관찰한 기존 test를 다시 사용한 비교이므로 독립적인 새로운 현장 시험도 필요하다.

결과와 새 모델은 `runs/normal-facility-20261117/retrained-comparison`에 있다. `results.json`, 두 `*-predictions.json`, `excluded.json`에 임계값·세션별 점수·제외 사례를 저장했다. 학습 코드는 `runs/normal-facility-20261117/retrain_compare.py`다. DB·GitHub·대시보드는 변경하지 않았다. 모델은 실험용이며 `production_ready=false`다.
