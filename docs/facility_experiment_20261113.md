# 2026-11-13 주간 시설물 분류 실험

시선유도봉 정상/파손/쓰러짐/누락/차량 통과, 가드레일 정상/휘어짐/이탈/파손/차량 통과, 신호등 정상/전환/보행 신호 점멸/차량 신호 지속 소등을 Unity에서 생성했다. 배경 차량 위치와 주간 조도를 시드별로 바꾸며 각 상황당 분할별 3세션, 총 126세션/6048프레임이다. 상황·시드 및 전체 이미지 SHA 분할 감사는 통과했다. 같은 가상 도시와 카메라를 사용하며 정답과 가림은 사람 검수 전이다.

시설물 위치를 자동 검출하지 않는다. 합성 정답으로 오프라인 생성한 기준 ROI를 기준으로, 이미지 특징만 사용하는 OpenCV RTrees 이진 상태 분류기 세 개를 학습했다. 실영상 사용 시에는 검토된 카메라별 기준 ROI를 별도로 정해야 한다. 세션별 최대 5프레임 사용, 차량 상자가 ROI의 3% 초과 겹치면 해당 프레임 제외, 학습/검증/시험 세션 분리, validation으로 임계값 선택, test로 고정 평가했다. 차량 박스 기반은 가림의 불완전한 대용이다.

시선유도봉 시험 15세션: 이상 9 중 TP8/FN1, 정상 6 중 FP1. 가드레일 시험 15세션: 이상 9 중 TP9/FN0, 정상 6 중 FP5. 신호등 시험 12세션: 소등 3 중 TP1/FN2, 정상 9 중 FP7. 각각 실제 이벤트 수가 아닌 소규모 합성 세션 수다. 신호등 모델은 사용 불가이며 세 모델 모두 production_ready=false다.

validation ROI와 test ROI의 첫 표본에 대한 pHash 진단에서 가장 가까운 ROI 거리가 4비트 이하인 test 세션은 시선유도봉 14/15, 가드레일 14/15, 신호등 12/12였다. 완전 동일한 바이트라는 뜻은 아니지만 고정 배경의 근접 중복이 심해 위 점수로 일반화 성능을 주장할 수 없다. 고유 카메라·현장 분리, 현실적 시설물·정상 기준·라벨과 가림/전환 시간 검증이 필요하다.

`detection/facility_state.py`의 실험용 추론기는 외부가 제공하는 `visible`, `camera_stable`, `transition_or_flashing`이 유효할 때만 ROI 점수를 계산하며, 가림·불안정·전환/점멸·프레임 간격 초과는 unknown으로 되돌린다. 일정 시간 연속 증거가 쌓인 뒤에만 `suspected_change` 또는 `suspected_dark`를 반환한다. 가림·점멸을 자동으로 인식하는 기능, 실제 CCTV 검증, 대시보드 자동 경고 연결은 구현하지 않았다.

상세 결과와 해시는 `runs/day-hazards-20261113/facility/results.json`, 분할 검사는 `split-audit.json`, pHash는 `phash-audit.json`, 재현 코드는 `train_facilities.py`다. 검증에 `python -m unittest discover -s detection/tests` 61개가 통과했다. Unity 6000.6.6f1 재컴파일 오류 0, 연속 촬영과 완료 확인 후 Play를 종료했다.
