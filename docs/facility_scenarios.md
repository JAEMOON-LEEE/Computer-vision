> 2026-11-17에 맨홀 상황과 새 시설물 학습 실험이 추가됐다. 아래의 14상황·미검증 기록은 당시 상태이며, 현재 기본 상황은 맨홀 3종이 추가된 17종이다. 최신 결과와 한계는 `manhole_facility_20261117.md`를 확인한다.

2026-11-11. 아래는 코드에 추가한 합성 상황이다. Unity 컴파일·Play 장면 확인, 실제 영상 자료 수집, 모델 학습·평가는 아직 수행하지 못했다.

## 구현한 상황

- 시선유도봉: 정상, 상단이 짧아진 파손, 옆으로 기운 쓰러짐, 누락, 정상 봉 옆 차량 통과. 봉은 단순 주황색 직육면체이고 파손 단면이나 실제 제품 형상은 모사하지 않는다.
- 가드레일: 정상, 중앙 단의 수평 회전과 밀림으로 표현한 휘어짐, 빔의 옆쪽 이탈, 중앙 단이 빠진 파손, 정상 난간 옆 차량 통과. 빔과 지주는 단순 직육면체다. 고정구 파손이나 물리 변형은 모사하지 않는다.
- 신호등: 정상 주기, 차량 신호 황색에서 전환, 기존 보행 신호 녹색 점멸, 차량 신호등 0번의 전 등화 지속 소등. 기존 신호 제어기와 메시를 재사용한다. 소등은 선택된 램프의 표시만 끄며 제어기의 내부 신호 단계는 진행된다. 셰이더 소등 제어를 적색·황색·녹색에 적용했다.
- 시드 기반으로 봉·난간 위치 X, 크기, 일부 기울기·파손 길이·이탈 폭을 바꾼다. 주간·야간은 기존 조명 생성기를 사용한다. 차량 통과 사례는 단순 정속 이동이며 실제 카메라 시점에서 가림이 생기는지는 미확인이다. 가림 비율 정답이나 카메라별 기준 정합은 구현하지 않았다.

`FacilityTruth`는 시설물 ID, 종류, 정상/이상, 변형, 기준 및 실제 위치, 크기·각도·이탈, 존재 여부와 신호등 인덱스를 프레임의 `scenario.facility`에 기록한다. `visibility=not_measured`는 보임 또는 가려짐을 판정하지 않았다는 뜻이다. 정답은 합성 상황 확인용이며 추론에 입력하지 않는다. 누락은 기준 위치와 `present=false`로 표시한다. 차선·시설물 배치는 가상 도시의 고정 카메라용이고 실제 위치로 사용할 수 없다.

## 수집 방법 및 분할 검사

CityTrafficLab을 Play한 뒤 Unity 메뉴 `TwinSight / City Lab / Capture Facility Cases (Play Mode)`를 실행한다. `FacilityCapture`는 기본 14상황×주야간×train/val/test, 각 96프레임/8fps를 각각 독립 세션으로 저장한다. `seedBase`, `repetitions`, `framesPerClip`, `captureFps`, `onlyCase`, 출력 경로는 컴포넌트 설정으로 조정한다. 이 수치는 계획된 출력이며 아직 생성된 자료 수가 아니다. 출력은 `D:\Capston disign` 아래 빈 폴더만 허용하고 기존 결과를 덮어쓰지 않는다. 전체 촬영 후 Play 모드를 종료해야 기존 씬 설정이 복원된다.

`Run-ProjectPython.ps1 -m detection audit-facility --train <학습세션들> --val <검증세션들> --test <시험세션들>`로 생성한 세션 경로들을 넘긴다. 프레임 순서, 상황/상태, 시드, 세션 재사용, 분할 간 시드 및 정확히 같은 이미지 SHA-256을 검사한다. 감사는 데이터 변환이나 모델 검증이 아니다. 다른 시드의 근접 중복, 영상 재인코딩, 공통 에셋·동일 CCTV 구도와 실제 CCTV 일반화는 보장하지 않는다.

## 학습·판정·대시보드 연결의 한계

현재 기존 `barrier`는 범용 콘크리트 구조물이며 가드레일 상태를 뜻하지 않는다. 기존 YOLO 라벨은 객체 박스라 시설물 누락·파손 정도나 신호등 시간 상태를 표현하지 못한다. 따라서 기존 `prepare-unity`는 시설물 세션을 거부한다. 시설물 검출용 가시 영역 박스와 기준/상태·시간 정답의 별도 스키마, 사람 검수, 데이터 변환·평가와 모델 학습이 필요하다. 기존 대시보드에서 이 기능을 지원하는 것처럼 표시하지 않았다.

가림 시 미관측을 유지하고 가림 해소 후 여러 프레임을 확인하는 시설물 상태 판정, 신호 전환 유예·정상 점멸 식별·지속 소등 의심 판정은 미구현이다. 실제 영상에서 기준 카메라가 이동했거나 보이지 않으면 판단을 보류해야 한다. 영상만으로 고장을 확정하지 않는다.

## 확인 결과
