# 주간 전체 화면 통합 YOLO11n 실험

## 학습과 범위

포트홀·낙하물·시선유도봉·맨홀·가드레일을 하나의 YOLO11n에서 다루는 실험을 수행했다. 클래스는 포트홀, 낙하물, 유도봉 정상·파손·쓰러짐, 맨홀 정상·이상, 가드레일 정상·이상 총 9개다. 신호등과 차량 충돌은 새 학습에 넣지 않았다. 유도봉 누락은 빈 정답이지 별도 검출 클래스가 아니므로 누락 고장 판정은 평가하지 않았다.

기존 모델을 보존하고 사전학습 YOLO11n에서 CPU로 20에폭, 이미지 크기 512, 배치 8, 시드 261118, 첫 10개 블록 동결해 학습했다. 검증 결과로 선택된 `runs/unified-yolo-20261118/training/weights/best.pt` SHA-256은 `8a027f56276243faa95b46dd171abad433462fa9601894e5f1abe0f2c42bd150`이다. 입력은 CCTV 전체 화면이다.

주간 Unity 합성 이미지 학습 905장, 검증 709장, 시험 708장이다. 차량 없는 정상·이상 사례와 카메라에 가까운 위치의 사례를 포함한다. 전체 이미지 디코딩·라벨 형식, 원본 대조, 장면·시드 및 정확한 이미지 해시의 분할 중복 검사를 통과했다. 상세 기록은 `runs/unified-yolo-20261118/dataset-no-vehicle-audit-resumed.json`이다. 동일한 Unity 도시·유사한 카메라와 에셋을 사용하여 시각적으로 유사한 장면이 남는다.

## 성능

객체 검출 AP는 IoU 0.5, 101점 보간이다. 정밀도·재현율 집계의 TP·FP는 신뢰도 0.25, IoU 0.5 기준이며, AP는 다양한 신뢰도 순위를 사용한다. 시설물은 정상·이상 각각 별개 클래스로 평가했다.

| 대상 | 시험 정답 상자 | TP | FP | 시험 AP50 |
|---|---:|---:|---:|---:|
| 포트홀 | 103 | 42 | 29 | 0.415 |
| 낙하물 | 110 | 57 | 21 | 0.548 |
| 시선유도봉 정상 | 38 | 27 | 0 | 0.815 |
| 시선유도봉 파손 | 38 | 7 | 5 | 0.233 |
| 시선유도봉 쓰러짐 | 38 | 9 | 17 | 0.154 |
| 맨홀 정상 | 64 | 3 | 1 | 0.072 |
| 맨홀 이상 | 80 | 8 | 3 | 0.205 |
| 가드레일 정상 | 80 | 69 | 40 | 0.710 |
| 가드레일 이상 | 96 | 66 | 22 | 0.750 |

9개 클래스 평균 AP50은 validation 0.462, test 0.434다. 각각 단순 클래스 평균이며 시설물 이상을 모두 잘 감지한다는 뜻이 아니다. 신뢰도 0.25에서 이상 유도봉·맨홀 TP가 특히 적으며, 가드레일 정상 클래스에도 예측 박스 오탐이 많다. 여기의 FP는 해당 클래스 예측 박스 단위이지 정상 상황 이미지 단위 오경고나 시간당 경고 건수가 아니다.

차량 없는 근거리 test는 168장이다. 그 부분의 객체 AP50은 포트홀 0.606, 낙하물 0.746, 유도봉 정상·파손·쓰러짐 각각 1.000, 맨홀 정상 0.141·이상 0.425, 가드레일 정상 0.761·이상 0.808이다. 유도봉 클래스별 정답은 각각 4개뿐이므로 1.000으로 일반 성능을 주장할 수 없다.

## 한계와 중단 상태

Unity 렌더러의 투영 박스는 가림을 고려한 보이는 영역 정답이 아니며 전수 사람 검수 전이다. 원거리 시설물이 구조물과 겹친 표본이 있고 맨홀 등은 작고 단순한 합성 에셋이다. 알려진 주차 차량 메시와 추적 차량은 차량 없는 촬영에서 제거했으나 모든 정적 장면은 전수 확인하지 않았다. 실제 CCTV, 새 카메라, 실제 차량 가림, 영상 시간 경과에 따른 안정성은 평가하지 않았다. 이전 실험에서 이미 관찰된 시험 장면이 포함돼 독립 최종 시험도 아니다. 모든 모델은 실험용이며 `production_ready=false`다.

validation/test 추론이 완료된 직후 사용자가 시험 완료 후 멈추고 검증 이미지 추가 추론을 하지 말라고 요청했다. 따라서 기존 도로 모델의 동일 시험 세트 재추론, 프레임 단위 시설물 경고·정상 도로 오경고 집계, 별도 추가 검증 추론은 실행하지 않았다. 기존 모델과 비교할 때 동일 시험 데이터가 아니거나 객체 검출 AP와 상태 분류 AP가 달라 직접 비교하면 안 된다. 기존 모델·DB·GitHub는 변경하지 않았다.

`runs/unified-yolo-20261118/{training,eval-val,eval-test,subset-val.json,subset-test.json}`에 가중치·검출 결과·근거리 부분집합 지표를 보존한다. 표본 수와 원본 추적은 `dataset-no-vehicle/manifest.json`에 있다.
