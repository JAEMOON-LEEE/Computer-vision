# 주간 상황별 대표 이미지 및 정답 점검

## 원본 정답 검사

기존 Unity 시설물 714세션의 20,160개 이미지와 `ground_truth.jsonl` 20,160개 레코드가 일대일로 존재하는지 확인했다. 레코드별 시드·에피소드·상황·상태·시설물 종류·정상/이상·존재 여부, 이미지 크기·연속 프레임·시간, 분할 간 시드와 바이트 동일 이미지도 검사했다. 시선유도봉·가드레일·맨홀 외 기존 신호등 자료도 원본 검사에 포함했지만 새 후보 데이터에는 넣지 않았다.

주간 포트홀·낙하물 YOLO 데이터셋 359개 이미지에 대응하는 정답 텍스트가 모두 있고, 클래스와 좌표가 원본 Unity 정답의 변환 규칙과 일치하는지 검사했다. 빈 라벨 128개는 원본에서 `Normal`로 기록된 이미지이며 누락된 라벨 파일이 아니다. 객체의 실제 가시성이나 정답 박스의 물리적 정확성을 사람이 전수 확인한 것은 아니다. 원본 검사 결과는 `runs/unique-labeled-day-20261117/{facility-audit.json,facility-inventory.json,source-audit.json}`이다.

## 서로 다른 상황 후보 구성

원본을 변경하지 않고, 각 시설물 시드·에피소드에서 차량 박스와 기준 영역이 3% 초과 겹치지 않는 대표 프레임 하나를 선택했다. 모든 프레임이 이 기준에 걸리는 시설물 세션 54개는 보류했고, 정상 기준과 대상이 짝인 자료 중 기준 측 54세션은 별도로 보존해 대상과 같은 상황을 중복 선택하지 않았다. 이 2차원 겹침 검사는 실제 가시성을 입증하지 않는다. 포트홀·낙하물은 저장된 각 이미지가 별도의 시뮬레이션 에피소드여서 기존 라벨과 함께 가져왔다. 같은 상황의 연속 프레임을 여러 장 선택하지 않는다.

첫 후보에서 동일 이미지와 보수적 시각 유사 규칙(pHash 거리 4 이하, 전체 축소 영상 평균 픽셀 차 2.5/255 이하, 시설물 관심 영역 또는 도로 위험 영역 차 3.5/255 이하)을 적용했다. 매우 비슷한 모습인데 정상·이상 상태가 다른 91장과 동일 상태의 매우 유사한 63장은 자동으로 정답을 바꾸지 않고 보류 목록에 넣었다. 남긴 **775장**의 모든 이미지와 정답 파일 쌍을 재검사했으며 원본 자료는 그대로다. 이 넓은 후보는 `runs/unique-labeled-day-20261117/candidate`에 있다.

넓은 후보에서 같은 작업·대상의 서로 다른 분할 간 pHash 거리 4 이하인 **유사 가능성 1,363쌍**이 남았다. pHash 유사성은 실제 중복의 확정이 아니지만, 사용자의 요청에 맞춰 더 보수적으로 처리한 `strict` 묶음을 별도로 만들었다. 정상·이상·대상·분할별 최소 1장을 유지하면서 181장을 추가로 제외했고, 위 조건의 분할 간 pHash 후보가 남지 않도록 검사했다. pHash가 다른 상황도 비슷한 배경 때문에 제거할 수 있으므로 제외가 정답 오류를 뜻하지 않는다.

| 대상·상태 | 학습 | 검증 | 시험 | 합계 |
|---|---:|---:|---:|---:|
| 시선유도봉 정상·이상 | 18 | 17 | 21 | 56 |
| 가드레일 정상·이상 | 22 | 51 | 30 | 103 |
| 맨홀 정상·이상 | 56 | 46 | 47 | 149 |
| 포트홀 | 67 | 17 | 19 | 103 |
| 낙하물 | 80 | 24 | 24 | 128 |
| 두 도로 위험이 없는 정상 | 50 | 3 | 2 | 55 |
| **합계** | **293** | **158** | **143** | **594** |

각 행의 도로 위험 수는 해당 클래스가 하나 이상 있는 이미지 수이며 객체 상자 개수가 아니다. 엄격 필터 뒤 도로 위험 없는 정상은 validation 3장, test 2장뿐이어서 통계적으로 균형 잡힌 성능 평가용으로 부적합하다. 정상과 이상의 정확한 구성은 `strict/summary.json`을 확인한다.

## 라벨 형식 및 한계

- 포트홀·낙하물 286장은 `strict/road_detection/images`의 이미지와 `labels`의 YOLO 상자 텍스트가 짝이며, 정상 55장의 빈 텍스트는 정상 표시다. `dataset.yaml`은 로컬 경로를 가리킨다.
- 시설물 308장은 `strict/facility_state`에 종류·정상/이상·변형·시드·에피소드·기준 관심 영역과 원본 정답 레코드가 JSON으로 저장된다. **이 관심 영역은 시설물의 정확한 객체 경계 상자(YOLO 검출 정답)가 아니다.** 시설물 상태 분류용 합성 정답이며 사람의 검토 전이다.
- 엄격 묶음 594장과 594개 라벨, 복사 후 해시, 한 에피소드당 한 장, 분할 간 시드 분리 및 정확히 같은 이미지가 없음을 검사했다. 같은 작업·대상에 한해 분할 간 pHash 경고 후보는 없지만, 이 기준만으로 모든 사진이 의미상 완전히 다른 상황임을 증명하지 못한다. 동일 Unity 도시·시설물·유사 시점이며 실제 CCTV나 새로운 카메라를 대표하지 않는다.
- 자동 생성 정답·가림·작은 물체의 가시성은 사람의 전수 검수 전이다. 따라서 두 묶음 모두 `candidate_human_review_required`로 표시했고, 새 모델을 학습하거나 성능 향상으로 주장하지 않았다. 다른 DB·GitHub 자료나 기존 데이터셋은 변경하지 않았다.

추천 검토 자료는 `candidate/review`의 표시 이미지, `candidate/excluded.json`의 보류 목록과 `candidate/cross-split-phash-review.json`의 유사 후보다. 엄격 묶음의 제외 목록은 `strict/excluded-images.json`, 재검사 결과는 `strict/verification.json`이다. 관련 Python 테스트 67개가 통과했다.
