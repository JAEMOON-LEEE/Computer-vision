# 주간 가드레일·맨홀 정상 사례 보강

기존 시험에서 가드레일 정상 5개 중 5개, 맨홀 정상 5개 중 3개가 오경고된 점을 바탕으로 정상 사례를 추가했다. 기존 데이터와 학습 모델은 보존했으며, 이번 보강만으로 오탐이 감소했다고 볼 수 없다. 재학습이나 새로운 성능 평가는 하지 않았다.

## 실제 구현한 변형

- 가드레일: 기존 직선 정상형과 차량 통과형에 더해, 세 구간 회전(양쪽 4도)과 측면 위치를 소폭 바꾼 완만한 형태, 구간 겹침을 늘린 연결부, 밝은 회색 색상, 인공 그림자를 추가했다. 구간별 위치·크기는 기존 시드 기반 설정을 사용한다. 실제 도로의 곡률이나 연결부 규격을 모델링한 것은 아니다.
- 맨홀: 기존 정상 덮개에 세 줄의 단순 무늬, 색상과 한 줄 표시로 표현한 마모, 인공 그림자, 같은 차로의 차량 통과 상황을 추가했다. 덮개는 단순 원기둥이고 실제 재질·정교한 무늬는 아니다.
- 조명은 주간으로 한정하고 태양광 강도를 시드별로 변화시켰다. 그림자는 빛과 대상 사이에 그림자만 투사하는 물체를 두어 만들었다. 동일 시드의 맨홀 화면 비교에서 대상 부근 밝기가 달라지는 것을 확인했으나 모든 화면에서 그림자의 유효성을 검수하지는 않았다.
- 총 11개 정상 상황(기존 정상·차량 통과 포함), 분할별 각 상황 5시드, 세션당 연속 24프레임을 촬영했다. 시설물 기준 위치·실제 위치·크기·상태·변형과 시드 및 조명은 정답에 기록된다. 가시성은 `not_measured`이며 차량 박스의 2차원 겹침은 가림 판정의 대리 지표일 뿐이다.

## 확인 결과

- 새 자료는 train·val·test 각각 55세션/1,320프레임, 총 165세션/3,960프레임이다. 기존 맨홀·시설물 자료와 합친 360세션/8,640프레임에서 분할 간 세션, 시드 및 정확히 동일한 이미지의 중복이 없었고 정답·프레임을 검사했다. `combined-split-audit.json`에 기록했다.
- 새 자료에서 기준 ROI와 차량 박스가 3% 초과 겹친 프레임은 train 235개, val 240개, test 240개다. 2차원 겹침은 전후 관계를 알 수 없고 실제 가림임을 뜻하지 않는다. 모든 새 프레임에 시각 검토가 필요하다고 표시했다.
- 유사성 참고 검사로 새 train 정상 장면과 이전 test의 각 첫 프레임 ROI를 비교했다. 같은 종류 내 최근접 pHash 해밍 거리가 8 이하인 이전 시험 장면은 가드레일 16/25, 맨홀 5/15였다. 이 값은 판정 기준에 민감하고 가림 프레임도 포함하는 근사치이며, 서로 독립적인 시험을 보장하지 않는다. `old-test-vs-new-train-phash.json`에 개별 결과를 남겼다.
- Unity 6000.6.6f1 컴파일 성공, Play 수집 후 종료, 현재 콘솔 오류 0을 확인했다. 관련 Python detection 테스트 63개가 통과했다.

## 사용 시 주의

자동 생성 정답은 사람 검수 전이다. 하나의 Unity 도시와 제한된 에셋을 공유하고 카메라 위치 차이도 작다. 시드가 다르고 동일 이미지가 없더라도 비슷한 장면이 남을 수 있으며 실제 CCTV·새 카메라 일반화는 입증되지 않는다. 차량과 겹치는 예시는 실제로 가려졌는지 수동 확인이 필요하며, 정상형을 학습에 넣기 전에 기존 시험 세트와의 유사성 및 독립성을 재검토해야 한다. 이 결과는 배포 가능한 자동 가림 판정이나 오탐 감소 성능을 뜻하지 않는다.
