# 주간 도로 정상 상황 추가

## 생성

기존 Unity CityTrafficLab과 기존 SUV·소형차 에셋을 재사용해 도로에 포트홀·낙하물이 없는 주간 정상 장면 180개를 새로 만들었다. 상황 하나당 시드·세션·프레임이 하나다. 학습 90개(시드 83000000~83000089), 검증 45개(84000000~84000044), 시험 45개(85000000~85000044)로 나눴다. 720×480 JPEG, Unity `ground_truth.jsonl`, 해당 카메라 정보, 장면별 `variation.json`을 남겼다. 차량 충돌·도로 위험·신호 고장 장면은 생성하지 않았다.

실제로 구현한 변화는 기존 CCTV 기준 위치의 X ±1.5, Y ±0.5, Z ±1.0 단위 이동, 로컬 피치 ±4도·요 ±5도, FOV ±3도, 주간 태양광 강도 0.85~1.35 및 방향 변화, 기존 차량 0~4대의 종류·차선·위치·방향, 정상 신호의 차량/보행 단계다. 차량 위치는 충돌을 의도하지 않은 고정 배치다. 비·야간·신규 도로/새 에셋은 만들지 않았다. 변형 값은 시드별로 기록되며 작은 스모크 재실행에서 2개 시드의 변형 JSON과 JPEG SHA-256이 각각 일치했다. 이는 모든 플랫폼에서 픽셀 단위 재현을 보장한다는 의미가 아니다.

Unity 컴파일과 Play 수집 및 종료를 확인했다. 새 180세션 모두 주간 `Normal` 상태·시드·카메라 위치/FOV 메타데이터 일치, 포트홀·낙하물 `TrackedObject` 부재, 이미지 크기·정확한 이미지 해시 및 기존 자료와 시드 중복 여부를 검사해 오류 0건이었다. 모든 프레임의 실제 노면이나 가림을 사람의 눈으로 검수한 것은 아니다. `normal-road-preview.jpg`에서 시드·차량 수별 일부 장면을 확인했다.

## 라벨 및 기존 데이터와 결합

도로 위험 검출 클래스가 포트홀과 낙하물뿐이므로 각 정상 이미지에 **빈 YOLO 텍스트 파일**을 생성했다. 빈 파일은 이 두 대상이 없는 정상 정답이며 라벨 누락이 아니다. 자동차가 있어도 이 두 클래스의 정답 상자가 생기는 것은 아니다. 각 사진의 원본 시나리오·조명·차량·카메라 메타데이터는 `expanded/new-normal-source-records.json`에서 추적할 수 있다.

기존 완화 후보 672장은 전부 보존하고 새 정상 180장을 별도 확장 후보에 추가했다. 이미지별 시드·에피소드, 원본 경로, 정답 파일, 바이트 해시를 보존했다.

| 주간 도로 위험 데이터 | 기존 | 추가 | 합계 |
|---|---:|---:|---:|
| 학습 정상 | 52 | 90 | 142 |
| 검증 정상 | 7 | 45 | 52 |
| 시험 정상 | 4 | 45 | 49 |
| **정상 합계** | **63** | **180** | **243** |

포트홀 이미지 103장과 낙하물 이미지 128장, 시설물 이미지 378장은 기존과 같다. 따라서 전체는 852장(도로 검출 474, 시설물 상태 378)이며 852개 정답 파일이 있다. 새 정상 사진만으로 기존 상태 분류나 객체 검출 모델을 재학습하지 않았다.

## 검사와 한계

새 데이터와 기존 자료는 같은 분할에서 시드·에피소드를 재사용하지 않고 바이트가 같은 이미지도 없다. 기존과 동일하게 정상 도로 사진의 분할 간 전체 화면 pHash 거리 2 이하는 제외하며, 재계산 결과 해당 쌍 0개였다. 거리 3~4의 유사 가능성은 23쌍이며 `normal-similarity-review-verified.json`에 있다. pHash로 장면의 독립성이나 시각적 고유성을 보증할 수 없다. 같은 Unity 도시와 에셋을 사용하므로 새로운 실제 CCTV·현장 일반화는 검증되지 않았다.

새 정상 사진에만 카메라 위치·방향 변화가 추가돼 모델이 위험 여부가 아니라 카메라 차이에 반응할 가능성이 있다. 실제 학습 전에 긍정(포트홀·낙하물)에도 비교 가능한 조건을 마련하고 정상·이상 정답 및 가시성을 검수해야 한다. 모델의 오탐 감소 여부도 검증하지 않았다. 라벨은 자동 생성되었고 데이터셋은 `candidate_human_review_required`다.

원본은 `simulation/TwinSightSim/TwinSightExport/normal-road-day-20261117`, 확장 데이터는 `runs/road-normal-more-20261117/expanded`, 수집·검증 기록은 `runs/road-normal-more-20261117`에 있다. 시설물 JSON의 기준 관심 영역은 객체의 정확한 YOLO 박스가 아니다. 관련 Python detection 테스트 67개가 통과했으며, 기존 데이터·모델·DB·GitHub는 변경하지 않았다.
