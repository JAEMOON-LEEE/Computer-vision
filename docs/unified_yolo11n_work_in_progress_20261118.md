# 통합 YOLO11n 작업 중단 기록 — 2026-11-18

사용자 요청으로 준비 작업만 마친 상태에서 중단했다. **통합 모델 학습과 validation/test 성능 평가는 시작하지 않았다.** 기존 개별 모델 및 데이터는 보존했고 DB·GitHub를 변경하지 않았다.

## 요청과 구현

단일 YOLO11n의 대상으로 포트홀·낙하물·시선유도봉·맨홀과 이전 목표의 가드레일을 포함했다. 신호등과 차량 충돌은 제외했다. 객체 클래스는 포트홀, 낙하물, 유도봉 정상·파손·쓰러짐, 맨홀 정상·이상, 가드레일 정상·이상의 9개다. 유도봉 누락은 빈 정답이며 누락 판정 클래스가 아니다.

기존 Unity 시설물 캡처에 opt-in 박스 출력, 차량 없는 촬영, 가까운 위치 옵션을 더했다. 맨홀은 구멍·덮개 그룹, 가드레일은 빔·기둥 그룹의 Unity 렌더러 투영 범위를 박스로 사용했다. 새 `NoVehicleRoadCapture.cs`는 기존 포트홀·낙하물 변형을 차량 없이 촬영한다. 차량 스포너와 추적 차량을 끄고 알려진 주차 차량 메시 하나를 숨겼으며 촬영 시 추적 차량 부재를 검사했다. 정적 장면 전체를 사람이나 자동 시스템이 전수 확인한 것은 아니다.

가까운 시설물과 도로 위험은 월드 X -1~5, 기존 원거리 시설물은 X 10~14 범위다. 근거리 표본 스크린샷 `runs/unified-yolo-20261118/closer-smoke-preview.jpg`와 `closer-road-preview.jpg`를 육안으로 확인했다. 실제 배치의 현실성, 전체 라벨의 가시성 및 정답은 사람 전수 검수 전이다. 가까운 추가 장면은 차량 없는 조건으로 촬영했으며 근거리 차량 가림 성능은 검증하지 않았다.

## 보존된 데이터와 검사 상태

- 기존 자료와 차량 있는 시설물 480장으로 구성한 초기 묶음 `runs/unified-yolo-20261118/dataset`은 이미지 1314장이고 데이터 형식, 시드·세션 및 정확한 이미지 해시의 분할 검사를 통과했다. 상세는 `dataset-report.json`과 `facility-split-audit.json`이다.
- 차량 없는 시설물 장면은 원거리 288장, 근거리 288장, 차량 없는 도로 정상·포트홀·낙하물은 원거리 216장, 근거리 216장이다. 각각 독립 시드·상황별 한 프레임으로 촬영했으며 `simulation/TwinSightSim/TwinSightExport/unified-yolo-{no-vehicle,closer-no-vehicle}-{facility,road}-20261118`에 있다.
- 이 1008장을 더한 `runs/unified-yolo-20261118/dataset-no-vehicle`에는 학습 905장, 검증 709장, 시험 708장, 총 2322장이 복사되었고 YAML·manifest·라벨이 생성되었다. 준비 스크립트의 소스 시드·세션·정확한 이미지 해시 교차 분할 확인은 복사 단계에서 통과했으나, 마지막 전체 이미지 디코딩·라벨 유효성 검사는 **사용자의 중단 요청으로 중단되었다**. `dataset-no-vehicle-report.json`과 `no-vehicle-excluded.json`은 생성되지 않았다. 이 후보를 검증 완료된 데이터로 취급하지 말 것.
- Unity 6000.6.6f1 컴파일 오류 0, Play 촬영과 종료를 확인했다. Python detection 테스트 72개 및 하위 테스트 15개 통과 후 가까운 위치 C# 코드가 추가되었고, 그 코드는 재컴파일 및 Play 표본 확인을 마쳤다.

## 재개할 때

`prepare_no_vehicle.py`는 보존을 위해 기존 출력 폴더가 있으면 중단하므로, 기존 후보를 지우거나 덮어쓰지 말고 저장된 manifest와 라벨을 대상으로 `detection.dataset.check_dataset` 및 `detection.facility_audit.audit_facility_splits`/`detection.prepare_unity.audit_hazard_splits`를 별도로 다시 수행하고 미완료 보고서를 작성한다. 모든 박스는 합성 객체의 가림을 반영하지 않는 투영 정답이며 일부 원거리 표본은 구조물과 겹친다. 상황별 표본, 정답 품질 및 근접 장면을 확인해야 한다.

검사가 통과되면 `runs/unified-yolo-20261118/train.py`는 해당 9개 클래스의 전체 프레임을 사전학습 YOLO11n으로 512 픽셀, 최대 20 에폭, CPU에서 별도 학습하도록 준비되어 있다. 시작 전 YAML 경로·클래스·가중치를 재확인한다. 이후 `evaluate.py`로 validation/test 및 차량 없는·근거리 부분집합을 평가한다. 이 스크립트도 실행 전 검토한다. 시드·장면 분리는 실제 CCTV나 새로운 카메라의 일반화를 입증하지 않는다. 모델 배포·DB 변경·GitHub 업로드는 요청되지 않았다.
