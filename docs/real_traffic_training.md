# 실제 CCTV 차량 검출·사고 장면 보강

## 목표와 현재 범위

가상환경의 다섯 클래스 검출기로 실제 트럭·버스와 고속도로 사고까지 판단하던 한계를 보완한다. 기존 `Detector`, ByteTrack, 박스 좌표·JSONL 형식, `WarningEngine`, 팀 대시보드를 재사용한다. Unity 모델과 자료는 보존한다.

**차량 검출**과 **사고 장면 분류**는 서로 다른 모델이다. `real-coco`(공식 COCO11s 범용 모델)와 `real-traffic`(MIO 검증으로 선택한 CCTV 보강 모델)는 사람·승용차·트럭·버스·오토바이·자전거 여섯 종류를 검출한다. 포트홀·낙하물·구조물은 이 모델들의 검출 대상에 포함되지 않는다. 해당 합성 실험은 기존 모델 선택으로 계속 사용할 수 있다.

범용 모델은 대시보드의 기본 선택으로 제공하고 CCTV 보강 모델도 비교 선택할 수 있다. MIO 검증 점수가 높다고 다른 카메라·특수 작업차에서도 항상 우수한 것은 아니다. 사용자 쇼츠의 한 화면에서 범용 모델은 작업 트럭을0.56으로 검출했지만 CCTV 학습 모델은 트럭 뒷부분을 car0.29로 잘못 분류했다. 이 화면은 학습에 넣지 않았고 정확도 산출용 정답을 모두 작성한 자료도 아니다. 이 관찰을 근거로 CCTV 모델의 val 선택을 바꾸지 않았으며 두 모델을 각각 제공한다.

사고 장면 후보는 실제 사고·정상 영상으로 학습하지만, 물리적 접촉 시각이나 충돌한 두 차량을 정답으로 갖고 있지 않다. 따라서 사고 현장·사고 이후 모습까지 포함하는 **장면 분류 실험**이며 정확한 충돌 순간 탐지기로 설명하지 않는다.

## 실제 차량 정답 자료

- 출처: [MIO-TCD 제공 기관](https://tcd.miovision.com/challenge/dataset.html), localization의 사람 정답 박스. 이용 조건은 CC BY-NC-SA 4.0이며 Luo 외, *MIO-TCD: A New Benchmark Dataset for Vehicle Classification and Localization*을 인용한다.
- 무작위 순서의 원본 tar에서 조건을 만족하는 서로 다른 이미지 800장을 선택한 소규모 선행 실험이다. 전체 벤치마크의 대표 표본이라고 보지 않는다.
- 원본의 `motorized_vehicle`, `non-motorized_vehicle`처럼 의미가 불명확한 대상이 있는 이미지는 통째로 제외해 미라벨 차량을 배경으로 학습하는 문제를 줄였다.
- articulated/single-unit/pickup truck → truck, work van → car, pedestrian → person으로 변환한다. COCO와 픽업트럭 분류 관례가 다를 수 있으므로 비교 시 이 차이도 고려한다.
- train459/val195/test146장. 트럭 정답은257/76/75개, 버스34/17/14개다. 여섯 클래스의 라벨·정규화·파일 누수를 기존 검사기로 확인했다.
- pHash 해밍 거리8 이하의 연결 그룹을 하나의 분할에 보존한다. 원본에 카메라 ID가 없어 **카메라가 완전히 분리된 평가가 아니다**. 근접 시점·유사 배경의 누수가 모두 제거됐다고 주장하지 않는다.
- 샘플 정답 박스4장을 시각 검사했으며 전체800장을 새로 수작업 검수한 것은 아니다.

가중치 학습은 공식 COCO YOLO11n에서8epochs/416/batch8/freeze10/CPU로 진행한다. COCO11n, COCO11s, 실제 CCTV 학습 후보를 동일한 val195장/640 입력에서 비교하고 **승용차·트럭·버스 AP50 평균**으로 선택한다. 새로 학습한 가중치를 자동으로 우선하지 않는다. 선택을 고정한 뒤 기존 합성 모델과 최종 모델을 test146장에 비교한다.

Windows가 선택적인 Matplotlib 확장 모듈을 차단해 차트 생성은 제외했다. 기존의 엄격한 데이터 검사와 Ultralytics의 학습·에포크별 검증·체크포인트는 유지한다. 마지막 독립 평가는 모든 후보에 같은 기존 이름 기반 평가기를 사용한다. 보안 설정은 변경하지 않았다. 실제 학습 인자는 `runs/real-traffic-v1/detector/args.yaml`, 에포크별 결과는 `results.csv`에 남는다.

## 실제 사고·정상 영상 자료

출처는 [TADBench 저자 저장소](https://github.com/UnicomAI/UnicomBenchmark/tree/main/TADBench)와 저자가 연결한 공개 Google Drive 압축본이다. Xu 외, *TAD: A Large-Scale Benchmark for Traffic Accidents Detection From Video Surveillance*, IEEE Access, 2025, DOI10.1109/ACCESS.2024.3522384를 인용한다.

공식 train의 사고·정상 각각 작은 영상60개를 선택하고, 각각12개를 고정된 파일명 해시로 validation에 분리한다. 공식 test의 사고16·정상16개는 학습·임계값 선택에 사용하지 않는다. 총152개, 원본 약1.54GB를 D드라이브에 보관한다. 서버의 전체4.54GB 압축본 대신 필요한 영상만 범위 요청으로 가져오며 ZIP CRC를 검사한다.

정답은 원본의 accident/normal 폴더에서 가져온 **영상 단위의 약한 라벨**이다. 프레임·접촉 쌍의 정답이 아니다. 원본 README에 별도 데이터 라이선스가 명시되지 않아 내려받은 원본을 GitHub에 재배포하지 않는다. 로컬 연구 실험으로 기록하며 외부 공개·상용 이용 조건은 별도로 확인해야 한다.

고정된 COCO YOLO11n의10번 계층에서256차원 특징을 추출해 OpenCV RTrees128개 트리를 학습한다. 각 원본 영상의 가운데 최대20초를2fps로 표본화한다. 이 구간에 실제 접촉 순간이 없을 수도 있고, 사고 전후 장면 모두가 사고 라벨을 받을 수 있다. 카메라 ID가 없어 같은 장소의 다른 영상이나 편집본의 근접 중복까지 완전히 분리했다고 보지 않는다.

깊이·임계값은 validation으로만 선택한다. 경고는 높은 점수가3회 연속·0.9초 이상 유지돼야 한다. val 사고 재현율50% 이상, 정상 영상 오경고율10% 이하인 경우에만 대시보드의 **실제 사고 장면 후보 분류 · 실험** 선택을 허용한다. 이 기준은 연구 후보를 보류하는 장치이며 실사용 인증이나 독립적인 안전성 검증을 뜻하지 않는다. 시험 결과로 다시 임계값을 조정하거나 활성화 여부를 바꾸지 않는다. 트리 투표 비율은 보정된 사고 확률이 아니다.

## 실행과 화면 사용

모든 원본·가중치·특징·임시 파일·캐시는 `D:\Capston disign` 아래에 저장한다.

```powershell
& 'D:\Capston disign\tools\Run-ProjectPython.ps1' -m detection.prepare_real_traffic
& 'D:\Capston disign\tools\Run-ProjectPython.ps1' -m detection.train_real_traffic
& 'D:\Capston disign\tools\Run-ProjectPython.ps1' -m detection.prepare_real_incidents
& 'D:\Capston disign\tools\Run-ProjectPython.ps1' -m detection.train_real_incident
```

자료 준비 명령은 제공 기관의 정답 CSV와 고정 SHA256의 공식 COCO11s 가중치도 필요한 경우 내려받는다. 원격 코드 파일은 실행하지 않는다. 소스 압축과 원본 정답은 `datasets/public-sources/real-traffic-v1`에 보존돼 있다. 완료된 데이터·학습 결과는 명령을 재실행해도 덮어쓰지 않는다.

1. `validation_lab.bat`로 대시보드를 열고 기본 **실제 영상 범용 모델 · 트럭·버스 포함**을 사용한다. **실제 CCTV 보강 모델 · 추가 학습**도 같은 입력으로 비교할 수 있다.
2. 화면 연결 또는 영상 파일을 선택하고 검은 여백·브라우저·자막을 제외해 도로 부분으로 분석 영역을 맞춘다. 유튜브 주소만 입력한 공식 플레이어는 자동 분석되지 않는다.
3. 실제로 카메라가 고정된 영상에서만 **고정 카메라 영상입니다**를 선택하고5/8fps로 사고 전부터 재생한다. 일반 충돌 의심은 기존의 추적·움직임 규칙을 사용한다.
4. 별도의 실제 사고 장면 분류는 검증 기준을 통과한 경우에만 선택할 수 있다. 차량 검출과 구분된 실험 경고이며 원본 영상을 사람이 확인해야 한다. 합성 전용 충돌 분류기를 실제 영상에 자동 적용하지 않는다.
5. 모델을 직접 끄고 결과를 D드라이브에 저장한다. 원본 입력 영상은 이 API가 자동 보관하지 않는다.

## 남은 과제

고속도로 사고, 야간·비·작은 차량·작업용 특수차, 사고 이후 찌그러짐과 가림을 충분히 반영한 실제 정답이 더 필요하다. 접촉 시각·참여 차량·비접촉 근접 주행·정상 정체를 사람이 표시한 자료와 카메라/사건 단위의 독립 시험을 마련해야 한다. 본 선행 실험 결과만으로 실제 CCTV 사고 인식 완료나 낮/밤 전체 성능을 보장하지 않는다.

## 완료 결과 (2026-10-25)

실제 CCTV 차량 학습8회와 후보 비교를 완료했다. 선택된 추가 학습 모델은 `mio_n`이다. val의 승용차·트럭·버스 AP50평균은 COCO11n0.3057, COCO11s0.3965, MIO 학습0.5357이다. 시험 데이터로 후보를 다시 선택하지 않았다.

대시보드의 실제 영상 범용 모델로 사용자 영상 정지 화면의 작업 트럭 박스, 별도 TAD validation video106의0~5초/5fps26프레임 처리·1.2초 장면 경고·자동OFF·D 보고서 저장을 확인했다. 경고 시각을 물리적 접촉 정답으로 확인한 것은 아니다. MIO 모델의 큰 버스 누락 사례도 결과에 남겼다.113개 검사·7subtests·TypeScript/Vite 빌드 통과.
