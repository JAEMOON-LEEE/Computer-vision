# 주간 도로 위험·시설물 성능 재평가

## 모델 선택과 시험 방법

가드레일과 맨홀은 네 기존 후보(HOG/색상 정상 보강형, HOG/색상 이상 보강형, YOLO 임베딩형, 임베딩+Sobel형)를 **공통 validation 세션**으로 비교했다. 공통 세션은 가드레일 정상 30·이상 15개, 맨홀 정상 25·이상 10개다. 0.05 간격의 각 후보 임계값 가운데 이상 탐지율 90% 이상을 만족하면서 정상 오탐이 가장 적은 후보를 골랐다. 동률이면 이상 탐지 수가 많은 쪽, 이후 고정된 후보 순서로 선택했다. 90%는 선택을 위한 예시 기준이며 실제 안전 요구나 시험 보증이 아니다. validation의 오탐도 가드레일 20/30, 맨홀 11/25로 높아 선택 모델을 사용 가능하다고 볼 수 없다. 선택 내역과 모든 후보는 `runs/facility-evaluation-20261117/selection.json`이다.

선택된 가드레일은 임베딩+Sobel RTrees(임계값 0.50), 맨홀은 정상 보강 HOG/색상 RTrees(0.30)다. 시선유도봉은 기존 주간 시설물 HOG/색상 모델(0.70)을 재평가했다. 포트홀·낙하물은 이 시설물 분류 모델과 별개의 기존 주간 YOLO 검출 모델을 재평가했다. 서로 다른 대상과 데이터로 학습했으므로 하나의 통합 모델이 아니다. 재학습 없이 저장된 가중치를 로드했고, 각 가중치 SHA-256과 이전 예측 점수 또는 도로 위험 재평가 결과가 기존과 동일함을 확인했다.

시설물은 기존 시험과 이후 수집된 정상 기준 짝 데이터의 target 중 test만 별도로 재추론했다. 짝 자료는 모델 학습에 들어가지 않았으나 앞선 기준 비교 실험에서 이미 관찰됐고 같은 가상 도시·에셋·비슷한 카메라를 공유한다. 5개 프레임(2·6·12·18·22)의 점수 평균으로 세션 상태를 판정하고 ROI와 차량 정답 박스가 3% 초과 겹친 프레임은 제외했다. 프레임이 모두 제외된 차량 통과 시선유도봉 5, 가드레일 10, 맨홀 5세션은 시험 통계에서 빠졌다. 자동 가림 판정은 평가하지 않았다. ROI 및 차량 박스는 시뮬레이션 정답에서 얻은 것이며 실시간 CCTV에서 검출된 것이 아니다.

## 시설물 시험: 기존 + 짝 target 합산

| 대상 | 평가 세션 | 이상 탐지/전체 | 정상 오탐/전체 | 상태 분류 AP |
|---|---:|---:|---:|---:|
| 시선유도봉 | 20 | 15/15 | 0/5 | 1.000 |
| 가드레일 | 74 | 33/41 | 25/33 | 0.645 |
| 맨홀 | 64 | 31/36 | 14/28 | 0.847 |

AP는 같은 점수의 정상·이상을 함께 처리한 101점 보간 **세션 상태 분류 AP**다. 객체 검출 AP가 아니다. 이전 구현은 동점 처리 순서에 따라 AP가 달라질 수 있어, 이번 최종값은 동점 그룹을 묶어 재계산했다. 임계값에서 가드레일 정밀도 33/58=0.569, 재현율 33/41=0.805이며 맨홀 정밀도 31/45=0.689, 재현율 31/36=0.861이다. 가드레일 누락 8개는 휨 1·중앙 파손 4·왼쪽 파손 2·오른쪽 파손 1이다. 맨홀 누락 5개는 이탈 1·옆 이탈 3·열림 1이다.

시선유도봉은 추가 짝 시험이 없어 기존 시험 20세션만 평가했다. 정상은 5세션뿐이고 차량 통과 5세션은 전부 제외됐으며, AP 1.000은 이 작은 합성 자료의 결과일 뿐 실도로 정확도 100%를 뜻하지 않는다.

시설물의 짝 target test는 대상별 9세션(정상 3·이상 6)이다. 이 부분만 가드레일 탐지 5/6·정상 오탐 2/3, 맨홀 탐지 5/6·정상 오탐 1/3이었다. 해당 짝의 기준 이미지는 분류 모델 추론에 사용하지 않았다. 나머지 시험 자료는 과거 반복 확인됐으므로 합산 통계는 탐색적이다.

## 주간 포트홀·낙하물 시험

기존 모델로 같은 67장에 다시 추론했고 이전 평가 수치가 재현됐다. 객체 박스 IoU 0.5, 정밀도·재현율 계산에 사용한 신뢰도 0.25다.

| 대상 | 정답 | 검출 TP | 오탐 FP | 객체 검출 AP50 |
|---|---:|---:|---:|---:|
| 포트홀 | 23 | 12 | 7 | 0.524 |
| 낙하물 | 30 | 13 | 0 | 0.577 |

두 클래스 평균 객체 검출 mAP50은 0.551이다. 작은 위험물의 상자가 모두 빠진 프레임은 이 시험 복사본에서 제외됐고 정답의 사람 검수·가림 검수는 미완료여서 성능이 낙관적일 수 있다.

## 제한과 파일

모든 시험은 주간 합성 자료, 동일 Unity 도시·에셋 및 유사 카메라다. 정확한 이미지·시드 분리 검사를 통과했어도 근접 유사성이 남아 있으며 실제 CCTV나 새 현장의 일반화는 미검증이다. 테스트와 검증 세트가 실험 반복 과정에서 이미 확인돼 독립적인 최종 검증도 아니다. 높은 시설물 오탐과 누락을 고려해 모든 모델은 `production_ready=false`다.

모델 선택·개별 예측·제외·결과는 `runs/facility-evaluation-20261117/{selection.json,predictions.json,evaluation.json,final-metrics.json}`, 주간 검출 결과는 `road-test/metrics.json`에 있다. Python detection 테스트 67개가 통과했다. DB·GitHub·기존 모델은 변경하지 않았다.
