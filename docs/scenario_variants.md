# 가상 도로 상황 변형

CityTrafficLab의 RoadScenarioDirector에 상황 변형을 추가했다. 이 문서는 생성 설정에 대한 설명이며, 영상 수집이나 모델 성능 검증 결과가 아니다.

- 차량 충돌: 기존 일반·고속 후방 추돌, 정면, 측면, 연쇄에 주행 중 앞차 추돌과 일부 겹친 후방 추돌을 추가했다. 자동 충돌 표본에 포함된다. F1~F5는 기존 다섯 장면이다.
- 포트홀: 작은 포트홀, 넓은 포트홀, 길쭉한 포트홀, 두 개가 모인 포트홀. 일반 자동 상황 및 숫자 2 선택 시 무작위로 나온다. 포트홀은 도로를 실제로 파내지 않은 시각적 표현이다.
- 낙하물: 작은 블록, 큰 블록, 납작한 판, 두 블록. 일반 자동 상황 및 숫자 3 선택 시 무작위로 나온다. 모두 기존 콘크리트 재질을 사용한다.
- 적색 신호위반: F7 정방향, F8 반대방향, F9 빠른 정방향. 적색 상태에서 차량 앞부분이 정지선을 넘을 때 `red_signal_crossing` 정답 이벤트를 기록한다. 자동 표본에는 포함하지 않았다. 기존 확률과 기존 수집 절차는 유지한다.

코드에서 `BeginPotholeEpisode`, `BeginDebrisEpisode`, `BeginSignalViolationEpisode`, `BeginVehicleCollisionEpisode`에 각 enum 값을 전달해 특정 변형을 선택할 수 있다. `scenario_variant`와 기존 `collision_variant`는 프레임 정답에 기록된다. 자동 학습용 기존 cleanDatasetCapture는 기존 포트홀·낙하물 생성 방식을 유지한다. 새 변형은 별도 수집·정답 및 실제 물리 검증 후 학습에 사용해야 한다. 신호위반 경고 모델을 새로 학습하거나 구현한 것은 아니다.

Unity Editor 6000.6.6f1에서 스크립트 컴파일을 진행했으나, Editor 연결 시간 초과와 종료로 새 장면의 시각화 및 실제 충돌·정지선 통과 검증은 아직 수행하지 못했다. 양쪽 차선의 정지선과 실제 도로 표시가 일치하는지도 확인 중이다.
