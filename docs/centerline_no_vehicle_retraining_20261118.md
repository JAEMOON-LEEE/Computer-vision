# 차량 없는 중앙선·근거리 시설물 재학습

## 생성과 정답

기존 CityTrafficLab의 주황색 중앙선 기준인 월드 Z=-0.41을 재사용하여 새 시선유도봉·가드레일의 정상 기준 위치를 그 위에 배치했다. 쓰러짐·이탈 등은 해당 기준에서 변형된다. 맨홀을 포함한 새 시설물의 X는 -7~-3으로, 직전 근거리 X=-1~5보다 카메라 쪽이다. 중앙선과 화면 위치는 `runs/centerline-near-20261118/smoke-preview.jpg`의 표본과 기록된 기준 좌표로 확인했다. 지형 축척과 실제 도로 시설물 배치가 검증됐다는 뜻은 아니다.

주간 정상·파손·쓰러짐·누락·휘어짐·이탈·열림·그림자·마모 등 이미 구현된 24종을 분할별 시드 12개로 생성해 새 장면 864장(train/val/test 각 288)을 수집했다. 한 상황에 한 장이며 새 상황의 시드·세션·정확 이미지 해시 분할 중복 검사를 통과했다. 시선유도봉 누락은 빈 박스로 기록하며 누락 고장 클래스는 아니다. 맨홀은 구멍·덮개 그룹, 가드레일은 빔·기둥 그룹의 투영 상자다. 전수 사람 검수 및 가시성 평가는 하지 않았다.

신규 촬영은 차량 스포너·추적 차량을 제거하고 기존에 확인된 정적 주차 차량 메시를 숨겼다. 각 촬영 프레임에 추적 차량 클래스가 없음을 검사했다. 모든 정적 메시의 정체와 1,872장 전체 화면은 사람 전수 검수하지 않았으므로 차량이 완전히 없다는 시각적 확정까지는 아니다. 표본에는 차량이 보이지 않았다. 기존 차량 없는 촬영 1,008장만 추가해 총 train/val/test 각 624장을 구성했다. 이전 배치와 거리의 기존 시설물도 이 자료에 포함된다. 전체 데이터의 라벨 형식, 소스 차량 정답 부재, 시드·세션·정확 이미지 해시 분할 검사를 통과했다. 새 시설물의 기준 좌표도 전수 검사했다.

## 재학습과 비교

이전 통합 YOLO11n에서 시작해 9개 클래스, 512픽셀, 배치 8, CPU, 시드 261119, 첫 10개 블록 동결로 12에폭 재학습했다. **이번 재학습에 사용한 프레임은 차량 없는 촬영으로 기록된 자료뿐이지만**, 출발 가중치는 과거 차량이 있는 장면도 포함해 학습된 모델이다. 충돌·신호등 새 데이터는 사용하지 않았다. 학습 중 validation을 사용했고 별도의 validation 이미지 재추론은 수행하지 않았다.

이전 모델과 새 모델을 같은 차량 없는 시험 624장·입력 512에서 비교했다. IoU 0.5, 101점 보간 객체 AP50이며 TP·FP는 신뢰도 0.25 기준이다.

9개 클래스 평균 AP50은 0.257→0.709이다. 기존·새 시험 자료의 분포가 과거의 전체 시험과 다르므로 과거 mAP와 직접 비교하지 않는다. 새 중앙선·근거리 시험 288장만 보면 새 모델의 AP50은 유도봉 정상/파손/쓰러짐 1.000/0.911/0.899, 맨홀 정상/이상 0.963/0.943, 가드레일 정상/이상 0.977/0.986이다. 이 부분의 유도봉 각 클래스 정답은 12개뿐이며 동일 도시의 합성 자료이다.

신뢰도 0.25에서 한 프레임에 해당 시설물의 이상 클래스가 하나라도 나오면 경고로 보는 보조 집계(박스 IoU를 따지지 않음)는 전체 시험에서 유도봉 이상 경고 30/40, 정상 오경고 0/20, 가드레일 이상 114/120·정상 오경고 39/100, 맨홀 이상 75/100·정상 오경고 19/80이다. 유도봉 이상 9건, 가드레일 이상 1건, 맨홀 이상 23건은 어떤 해당 시설물 클래스도 검출되지 않아 판정 보류다. 유도봉 누락 20건은 이 집계에서 제외했다. 중앙선·근거리 부분만 보면 가드레일 정상 60건 중 18건, 맨홀 정상 48건 중 15건을 이상으로 경고했다. 단일 프레임·해당 클래스의 어디서든 나온 경고 기준이며 연속 영상의 시간당 오경고 성능은 아니다.

시험은 기존에 관찰한 일부 자료와 신규 유사 합성 시야가 섞여 있으며 학습·검증·시험은 같은 도시와 유사 에셋을 공유한다. 새 카메라·실제 CCTV·차량 가림에 대한 성능이 아니다. 검출 AP 상승에도 정상 오경고와 포트홀·낙하물 미검출이 남아 실서비스용이 아니다(`production_ready=false`).
