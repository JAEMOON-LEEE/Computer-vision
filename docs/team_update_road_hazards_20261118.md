# TwinSight 도로 위험·시설물 실험 공유 — 2026-11-18

이 브랜치는 포트홀·낙하물과 시선유도봉·맨홀·가드레일의 주간 합성 데이터 실험을 공유한다. **실제 도로에 적용할 수 있는 완성 모델이 아니라 연구용 결과**다. 아래 내용이 이전 날짜의 실험 문서보다 최신이다.

## 이번에 달라진 점

- 차량 충돌을 새 데이터 수집과 학습 대상에서 제외하고 기존 충돌 자산은 보존했다. 신호등 고장도 현재 학습 대상에서 제외했다.
- 기존 Unity 시나리오를 활용해 시설물 정상·파손·쓰러짐·휘어짐·이탈, 맨홀 정상·열림·덮개 이탈을 생성했다. 새 유도봉과 가드레일의 정상 기준은 도시 에셋의 주황색 중앙선이며, 맨홀을 포함해 카메라에 더 가까운 상황을 추가했다. 맨홀과 가드레일의 시각 표현은 단순 합성이다.
- 9개 클래스 통합 YOLO11n을 차량 없는 촬영 자료로 12에폭 재학습했다. 추적 차량은 제거했으며 알려진 주차 차량 메시는 숨겼다. 정적 메시 전수·사람 검수는 아직 끝나지 않았다. 시작 가중치는 과거 차량이 보이는 장면으로 학습된 이력이 있다.
- 검증과 시험은 각 624장이다. 같은 차량 없는 합성 시험에서 이전 모델 대비 평균 객체 AP50은 **0.257 → 0.709**였다. 세부 AP50은 유도봉 파손 0.693·쓰러짐 0.777, 맨홀 이상 0.720, 가드레일 이상 0.880, 포트홀 0.289, 낙하물 0.467이다. 정상 가드레일은 100프레임 중 39개, 정상 맨홀은 80프레임 중 19개에 이상 경고가 발생했다(신뢰도 0.25, 이미지 내 이상 클래스 검출 기준). 포트홀·낙하물 미검출과 정상 오경고 개선이 필요하다.

- 가중치: [`detection/models/centerline-no-vehicle-yolo11n.pt`](../detection/models/centerline-no-vehicle-yolo11n.pt), Git LFS. SHA-256 `d5fb75fc142eb5f8e5da3b675d010b70784255630be743dcbd1533f91a9664d4`. 전체 화면 512픽셀 입력 실험용이며 자동 배포·대시보드 연결은 하지 않았다.
- 클래스: `pothole`, `debris`, `delineator_normal`, `delineator_broken`, `delineator_fallen`, `manhole_normal`, `manhole_abnormal`, `guardrail_normal`, `guardrail_abnormal`. 유도봉 누락은 검출 클래스로 학습하지 않았다. 검출이 없으면 누락이나 정상으로 확정하지 않는다.
- 모든 시험은 동일 가상 도시와 유사 카메라 시야의 주간 합성 이미지다. 일부 기존 시험 자료는 이전 실험에서 관찰됐다. 가림을 고려하지 않은 투영 상자이고 정답에 대한 사람 전수 검수는 끝나지 않았다. 실제 CCTV·새 장소·새 카메라·차량 가림에 대한 일반화와 연속 영상의 오경고율은 미검증이다.
- 원본 캡처·전체 학습 데이터·실험 로그는 이번 브랜치에 포함하지 않았다. 기존 `runs/`·`datasets/`와 Unity 생성 결과는 Git 제외 대상으로, 학습·재현 스크립트는 [`experiments/centerline-no-vehicle/`](../experiments/centerline-no-vehicle/)에 참고용으로 제공한다. 이 스크립트는 기존 로컬 원본·이전 가중치와 `runs/centerline-near-20261118/` 경로를 필요로 해 이 저장소만 내려받아 바로 재학습할 수 없다.
