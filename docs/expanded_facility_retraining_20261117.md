# 주간 가드레일·맨홀 이상 상황 추가 재학습

## 추가한 합성 상황

기존 Unity 시설물 생성기에 여섯 가지 이상 변형을 추가했다. 가드레일은 3구간 중 왼쪽 누락, 오른쪽 누락, 기존 휨과 반대 방향 회전(15~35도)이다. 맨홀은 그림자를 투사한 열린 상태, 덮개의 짧은 이탈(크기 배율의 0.25~0.40), 옆 방향 이탈(0.65~1.0)이다. 원래의 중앙 구간 파손과 열린 맨홀도 새로운 시드로 추가 수집했다. 파손·열림은 단순 도형의 누락과 검은 원판으로 표현했으며 실제 가드레일 파손이나 도로 구멍의 물리·재질을 재현하지 않는다.

8상황 × 3분할 × 5시드로 120세션/2,880프레임을 주간 촬영했다. 대상 위치와 크기, 주간 광량 및 배경 차량은 기존 시드 기반 변화를 사용한다. 각 프레임은 시설물 종류·변형·정상/이상 상태·시드·기준과 실제 위치·조명 등을 기록한다. Play 수집과 여섯 변형의 예시 화면을 확인했다. 정답과 실제 가시성은 사람의 전체 검수 전이다. 이전 두 자료를 포함한 총 480세션/11,520프레임에서 분할 간 세션·시드·정확히 같은 이미지 중복 없이 정답 및 연속 프레임 검사를 통과했다.

## 학습과 시험

기존 데이터, 이전 정상 보강 데이터, 이번 추가 데이터의 train과 val을 각각 결합해 가드레일과 맨홀 ROI HOG·색상 특징 RTrees 모델을 별도로 처음부터 학습했다. 이전 모델과 자료는 보존했다. 차 충돌·신호등은 사용하지 않았다. 검증 세션 F1을 최대화하는 임계값을 고르고, 이전 모델은 그 모델의 기존 임계값을 유지했다. 가드레일 임계값은 0.50→0.45, 맨홀은 0.40→0.45다. 따라서 가중치와 임계값을 함께 비교한 결과다.

이전과 동일하게 세션당 2·6·12·18·22번 프레임을 표본으로 삼고 기준 영역과 차량 정답 박스가 3% 초과 겹치는 프레임을 제외했다. 모두 제외된 세션은 평가하지 않았다. 이전 test에서 이전 모델의 세션별 점수가 기존 결과와 동일함을 검증했고, 두 모델을 같은 세션으로 평가했다. 이번 추가 test는 이상 장면만 포함하므로 정상 오경고는 이전 test에서 평가했다.

| 대상 | 이전 test 정상 오탐: 이전→새 모델 | 이전 test 이상 누락: 이전→새 모델 | 이번 추가 test 이상 누락: 이전→새 모델 |
|---|---:|---:|---:|
| 가드레일 | 11/30 → 23/30 | 4/15 → 1/15 | 10/20 → 4/20 |
| 맨홀 | 3/25 → 23/25 | 3/10 → 0/10 | 6/20 → 0/20 |

추가 상황을 합한 시험에서 이상 누락은 감소했지만 정상 오경고가 급격히 증가했다. 가드레일은 이전 시험의 휨 1개와 새 시험의 중앙 파손 1·왼쪽 파손 1·오른쪽 파손 2개를 놓쳤다. 맨홀은 해당 합성 시험에서 이상을 놓치지 않았으나 정상 25개 중 23개를 오경고해 실사용하기 어렵다. 상태 분류 AP는 기존+추가 test 합산 가드레일 0.685→0.668, 맨홀 0.836→0.863이다. 객체 검출 AP가 아니며 적은 합성 표본에서 나온 수치다.

시험의 차량 통과 가드레일 10세션과 맨홀 5세션은 모두 2차원 겹침 기준으로 제외됐으므로 가림 대응 성능은 평가되지 않았다. 같은 가상 도시, 제한된 에셋과 유사한 카메라 시야에 의한 근접 중복 가능성이 크다. 시드 분리·정확한 이미지 중복 검사는 현실의 새 카메라나 독립 현장 일반화의 증거가 아니다. 시험 데이터가 작고 기존 시험을 반복 사용한 탐색 실험이며 실제 CCTV와 독립 현장 검증이 필요하다. 모델은 실험용이며 `production_ready=false`다.
