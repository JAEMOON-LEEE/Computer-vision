# 통합 데이터 라벨 1차 검수 시작 — 2026-11-18

## 범위와 방법

`runs/unified-yolo-20261118/dataset-no-vehicle`의 전체 2,322장 중 상황 변형과 기존·근거리·차량 없는 조건별로 한 장씩 결정적으로 추출한 100장(train 32, val 39, test 29)의 접촉 시트를 만들고 조수가 시각적으로 1차 확인했다. 이는 표본 점검이며 사람이나 도로 시설 전문가의 정답 검수·승인이 아니다. 100개 모두 사람 검수 대기 상태로 기록했고 통과 판정을 부여하지 않았다. 표본·원본·시드 매핑은 `runs/unified-yolo-20261118/review_start/review-register.json`, 접촉 시트는 같은 폴더의 `contact-01.jpg`~`contact-09.jpg`다.

또한 전체 이미지의 라벨 박스와 Unity 원본의 차량·사람 박스 2차원 겹침, 512픽셀 정사각형 입력으로 종횡비를 유지해 축소했을 때의 박스 크기를 산출해 후속 검수 후보를 표시했다. 대상이 실제로 보이는지, 앞뒤 깊이 순서가 어떤지, 정답이 맞는지를 판정하는 검사가 아니다. 정적 전선·가로등·시설물은 자동 겹침 검사에 포함되지 않는다.

## 초기 발견과 보류 사례

- **R016 / validation / 포트홀 Elongated**: 접촉 시트에서 정답 상자 위치가 차량에 덮여 포트홀을 확인하기 어렵다. 원본의 차량 투영 박스는 포트홀 상자와 100% 겹친다. 현재 가시성 기준에 따른 보류·수정 여부를 검토해야 한다.
- **R004, R006 / test / 유도봉 파손**: 상자가 작고 전선이 상자 부근을 지나 시각 판별이 어렵다. 조명·확대 원본과 정답 범위를 추가로 확인해야 한다.
- **R037, R039 / 가드레일 이탈**: 보행자가 시설물 영역과 겹치거나 근접해 보인다. 실제 가림 여부와 라벨 정책을 확대 확인해야 한다.
- **R061, R062 / 맨홀 옆 이탈**: 구멍과 이탈한 덮개를 하나의 긴 박스로 묶었다. 구현의 그룹 정답과 일치하는 형식이지만, 실제 검출 목적에 맞는 범위인지 별도 기준 합의가 필요하다.
- **R073, R082 / 맨홀**: 원거리·그림자·전선으로 대상과 상태를 식별하기 어려워 추가 확인이 필요하다. 맨홀·포트홀은 단순한 납작한 합성 표현으로 형태가 비슷해 보이는 사례도 있다.

## 후속 검수

검수자가 접촉 시트에서 원본을 열어 보이는 영역·상태·클래스·박스 범위를 확인하고, 보류·수정 이유와 사람 확인 여부를 기록한다. 특히 실제 가림과 그림자, 정답 없는 정상 이미지, 작은 유도봉·맨홀, 맨홀 이탈 그룹 박스를 우선 확인한다. 수정이 필요한 경우 기존 라벨을 덮어쓰지 않는 별도 후보에서 처리하고 분할을 다시 검사한다. 이번 작업에서 이미지·라벨·모델을 수정하거나 재학습·추가 모델 추론, DB·GitHub 변경을 수행하지 않았다.
