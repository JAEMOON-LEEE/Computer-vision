# 임베딩과 엣지 특징 결합 실험

## 구성과 학습

직전 실험에서 사용한 고정 YOLO11n 0~6층의 ROI 임베딩 2,048개에 Sobel 엣지 특징 256개를 이어 붙여 총 2,304개 특징을 만든 뒤, 가드레일과 맨홀의 OpenCV RTrees 분류기를 각각 새로 학습했다. 원본 128×128 RGB ROI를 흑백으로 바꾸고 3×3 가우시안 블러, 3×3 Sobel X·Y 크기 계산, `1020*sqrt(2)` 정규화, 16×16 영역 평균 축소를 적용했다. 엣지는 밝기 경계이므로 그림자나 차선도 포함될 수 있다. 사전 학습 YOLO 가중치는 고정했으며 엣지 강화 화면을 YOLO에 입력하거나 YOLO 검출기를 새로 학습하지 않았다.

가드레일 train 68세션/329프레임, 맨홀 train 55세션/275프레임으로 직전 임베딩 실험과 동일한 학습·검증·시험 세션과 프레임을 사용했다. 합성 정답에서 얻은 기준 ROI와 차량 박스 겹침 3% 초과 프레임 제외 기준도 동일하다. 시험 세션·프레임·정답·ROI는 기존 임베딩 실험의 예측과 대조했다. 각 모델 임계값은 validation F1이 최대가 되는 값으로 정했다. 가드레일 기존 0.40→엣지 결합 0.50, 맨홀 기존 0.50→엣지 결합 0.45다. 서로 다른 임계값이므로 모델과 임계값을 함께 비교한 결과다.

## 동일 시험 결과

| 대상 | 정상 오탐: 임베딩 → 엣지 결합 | 이상 누락: 임베딩 → 엣지 결합 | 상태 분류 AP: 임베딩 → 엣지 결합 |
|---|---:|---:|---:|
| 가드레일 | 30/30 → 23/30 | 0/35 → 7/35 | 0.764 → 0.633 |
| 맨홀 | 20/25 → 22/25 | 0/30 → 0/30 | 0.783 → 0.810 |

가드레일은 오탐이 줄었지만 휨 1개, 중앙 구간 파손 3개, 왼쪽 구간 파손 2개, 오른쪽 구간 파손 1개를 놓쳤다. 맨홀은 시험 이상 누락이 없었지만 정상 오탐이 늘었다. 가드레일 정상 시험의 밝은 색상 사례 5개와 그림자 사례 5개를 모두 오경고했다. AP는 동일 실험의 101점 보간 세션 상태 분류 AP이며 객체 검출 AP가 아니다. 결과는 엣지 특징과 그에 따른 분류기·임계값 변화의 결합 효과이며 엣지 하나만의 인과적 효과를 증명하지 않는다.

## 확인과 한계

Sobel 특징은 일정한 영상에서 0이고 밝기 경계 예시에서 양수가 되는지 확인했다. 저장된 특징 추출기와 각 분류기를 다시 불러와 시험 세션 한 개씩의 점수를 재현했으며 Python detection 테스트 64개가 통과했다. 이전 검사에서 세 데이터 묶음 총 480세션/11,520프레임의 세션·시드·정확한 이미지 분할 중복이 없었다.

시험 자료는 이미 여러 번 확인한 소수의 합성 장면이며 같은 Unity 도시·에셋, 유사한 시야와 근접 중복 가능성을 공유한다. 차량 통과 시험의 가드레일 10세션과 맨홀 5세션은 전부 2차원 차량 박스 겹침 대리 기준으로 제외되어 가림 대응을 평가하지 못했다. 실제 CCTV·새로운 카메라의 성능은 미검증이며 자동 ROI 등록 및 가시성 판단도 없다. `production_ready=false`다.

결과·모델·세션별 예측과 제외 기록은 `runs/facility-embedding-edge-20261117/training`, 학습과 엣지 추출 및 재불러오기 검사는 같은 상위 폴더에 저장했다. 원본 YOLO 가중치와 기존 모델·데이터는 보존했고 DB·GitHub는 변경하지 않았다.
