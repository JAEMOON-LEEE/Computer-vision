# 주간 맨홀·시선유도봉·가드레일 실험

## 생성과 정답

Unity CityTrafficLab에 맨홀 정상 덮개, 덮개 없는 열린 상태, 덮개가 옆으로 이탈한 상태를 추가했다. 뚜껑과 검은 구멍은 단순 원기둥 형태의 시각적 표현이며 실제 도로 메시를 뚫거나 실제 뚜껑 낙하 물리를 구현하지 않았다. 시드에 따라 X 위치, 두 차선, 크기 및 이탈 거리가 바뀐다. 기존 시설물·충돌 시나리오와 기존 모델은 보존했다.

주간 13변형(시선유도봉 5, 가드레일 5, 맨홀 3) × 분할 3개 × 시드 5개로 195세션/4,680프레임을 수집했다. 프레임에는 기존 `scenario.facility`의 종류, 변형, 상태, 기준·실제 위치, 시드가 기록된다. 세션과 시드는 분할을 넘지 않고, 전체 프레임의 정확히 같은 이미지 SHA-256 분할 중복은 없었다. train/val/test 카메라 위치는 각각 (-17.7,5.017,1.583), (-17,5.017,1.833), (-16.3,5.017,2.083)이며 같은 도시와 시야의 작은 이동이다. 새로운 실제 카메라나 독립 현장에 대한 일반화 검증이 아니다.

## 학습·시험 방법

기존 ROI HOG/색상 특징과 OpenCV RTrees 방식을 재사용했다. 새 데이터에서 시선유도봉·가드레일·맨홀 모델을 각각 **처음부터 다시 학습**했으며, 이전 RTrees를 이어 학습하거나 덮어쓰지 않았다. 실험용 오프라인 ROI는 합성 기준 위치를 이용하지만, 실제 추론은 사람이 설정·확인한 카메라별 기준 영역이 필요하다. 각 세션에서 2·6·12·18·22번 프레임을 표본으로 삼고, 차량 정답 박스가 ROI의 3%를 초과해 겹치는 표본을 제외했다. 다섯 표본이 모두 제외된 세션은 28개다. 특히 차량 통과 시선유도봉은 모든 분할에서 각 5세션이 제외됐고 시험 가드레일 차량 통과 5세션도 제외됐다. 따라서 이 시험은 가림 중 오경고 방지 성능을 입증하지 않는다.

임계값은 validation에서 선택했고 별도 test 세션별 표본 점수 평균으로 분류했다. 실제 객체 박스 검출 AP50이 아닌, 소규모 합성 세션 상태 분류 결과다.

| 대상 | 시험 세션 | 이상 탐지 | 정상 오경고 | 상태 분류 AP |
|---|---:|---:|---:|---:|
| 시선유도봉 | 20 | 15/15 | 0/5 | 1.000 |
| 가드레일 | 20 | 15/15 | 5/5 | 0.895 |
| 맨홀 | 15 | 10/10 | 3/5 | 0.954 |

맨홀 이상 10세션은 열린 상태 5·뚜껑 이탈 5개다. 가드레일은 정상 5개 전부를 오경고했다. 맨홀 역시 정상 5개 중 3개를 오경고해 실제 운용에 부적합하다. 시선유도봉 결과도 매우 적은 가상 표본에서 나온 것이며 정확도 100%나 실도로 성능을 뜻하지 않는다. 각각 이전에 학습한 모델과 데이터가 다른 별도 실험이어서 숫자만으로 개선을 주장하지 않는다.

가장 가까운 학습 ROI의 pHash 해밍 거리가 8 이하인 시험 세션은 시선유도봉 6/20, 가드레일 15/20, 맨홀 7/15였다. pHash는 근접 유사성 참고 지표일 뿐 독립성을 증명하지 못한다. 동일 도시·소수의 에셋, 단순 시각 표현, 사용자 검수 전 합성 정답과 작은 시험 규모는 모두 주요 한계다.

`detection/facility_state.py`는 `manhole`을 지원하며 외부가 제공하는 `visible`·`camera_stable`이 유효하지 않을 때 관측을 보류한다. 영상에서 자동으로 가림을 인식하거나 기준 시설물을 자동 발견하는 기능은 없다. 시험 이미지 재사용을 통한 추론 경로 점검에서는 연속 입력의 관찰 후 `suspected_change`와 가림 입력의 `unknown`을 확인했다. 이는 실제 가림 대응 평가가 아니다. 대시보드·실시간 서비스에는 연결하거나 배포하지 않았다. 모두 `production_ready=false`다.

## 검증과 위치

- Unity 6000.6.6f1 재컴파일 오류 0. Play 프레임 진행과 맨홀 이탈 화면·정답을 확인하고 본 촬영 후 Play를 종료했다.
- Python detection 테스트 62개 통과. 전체 데이터의 시드/세션/정확한 이미지 중복 검사는 `runs/manhole-facility-20261117/training/split-audit.json`이다.
- 가중치·시험 결과: `runs/manhole-facility-20261117/training/{manhole,delineator,guardrail}.xml`, `results.json`, `*-predictions.json`, `excluded.json`. 수집 원본은 `simulation/TwinSightSim/TwinSightExport/manhole-facility-day-20261117`.
- DB·GitHub는 변경하지 않았다. 특히 이전에 사용자가 제거를 승인한 시설물 DB 묶음은 다시 등록하지 않았다.
